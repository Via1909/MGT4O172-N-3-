# BeautyLoop — MGT4017 website

A responsive skincare website prototype based on the supplied wireframe.

## Files
- `index.html` — website structure
- `css/styles.css` — layout, colours, typography and responsive styling
- `js/main.js` — shopping bag demo, plan selection and mobile navigation

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of the `MGT4017` repository.
2. Make sure `index.html` is in the repository root.
3. In Settings → Pages, select Deploy from a branch, `main`, and `/ (root)`.
4. Visit `https://YOUR-USERNAME.github.io/MGT4017/`.

The shopping bag and plan selection are front-end demonstrations. Checkout, payments and contact email are not connected.
